# ML Mastery

This repository is designed as a practical and structured learning path for mastering Machine Learning with Python. It covers essential libraries, core ML algorithms, beginner-friendly projects, and interview-ready notes.

## Repository Structure

- `01_libraries/` - Python libraries used in ML workflows
  - NumPy
  - Pandas
  - Matplotlib
- `02_ml_concepts/` - Fundamental machine learning concepts and algorithms
  - Linear Regression
  - Logistic Regression
  - KNN
  - Decision Trees
  - Naive Bayes
  - Feature Engineering
  - Model Evaluation
- `03_projects/` - Real-world ML mini projects
  - Titanic survival prediction
  - House price prediction
- `04_Chatsheet/` - Quick references and interview preparation material
  - Interview Q&A
  - Cheatsheet

## Learning Roadmap

1. Start with Python data tools and visualization libraries.
2. Learn core machine learning concepts and algorithms.
3. Practice feature engineering and model evaluation.
4. Work on real projects to apply theory in practice.
5. Prepare for interviews using cheat sheets and Q&A notes.

## Prerequisites

- Python 3.x
- Jupyter Notebook or VS Code
- Basic understanding of Python programming
- Libraries such as NumPy, Pandas, Matplotlib, and Scikit-learn

## Setup

```bash
python -m venv .venv
source .venv/bin/activate   # Linux/macOS
.venv\Scripts\activate      # Windows
pip install numpy pandas matplotlib scikit-learn jupyter
```

## How to Use This Repository

- Open the notebooks in each folder and study them in order.
- Run each notebook cell by cell to understand the logic.
- Try modifying the code, experimenting with parameters, and observing results.
- Complete the project notebooks and compare your solutions.
